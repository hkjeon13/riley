기존 이벤트 발행 정책과 서빙 설정을 기준선으로 삼았다. 이전 빌드에서 관찰된 성능 실험은 입력·장비·바이너리에 연결하며, 새로운 수치 기준이나 기본값을 채택할 때는 종합 계획의 출력 불변성과 회귀 기준을 적용한다. [W2 결과](02-async-step-result.md) · [W3 결과](03-long-context-result.md) · [W4 정확성](04-long-accuracy-result.md) · [W5 운영 결과](05-mixed-soak-result.md)

W5의 두 30분 실행에서 종료 뒤 GPU·pinned 메모리와 요청 KV는 0이었다. Cache off의 후반 RSS는 +0.75MiB였고 cache on은 0.00MiB였다. 운영 검사기의 native 할당·오류·지연 판정은 통과했다. 최종 후보의 RSS 증가 0 조건은 추가 확인 대상으로 유지한다. [운영 품질 기준](../goal.md#33-운영-품질)

배포 이미지의 A100 추론은 소스 아카이브 전송 승인 대기 상태다. 승인된 검증 경로에서 이미지 ID와 실행 파일 해시를 고정한 뒤 대표 모델의 API·정확성·운영 근거를 연결해야 릴리스 판정을 갱신할 수 있다. [종합 완료 조건](README.md#8-종합-완료-체크리스트)
